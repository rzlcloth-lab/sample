# Panduan Admin Heaven Paint (1 halaman)

**Alamat dashboard:** `domain-kamu.com/#admin` (tambahkan `/#admin` di belakang alamat website).

1. **Login.** Mode Supabase: masuk dengan email + password admin. Mode lokal: buat password (minimal 8 karakter) saat pertama kali masuk.
2. **Ubah produk.** Tab *Produk* > *+ Tambah produk* atau *Ubah*. Isi nama, kategori, harga, satuan, foto, dan status stok. Harga kosong = tampil "Tanya harga via WhatsApp".
3. **Stok habis / tersedia.** Di daftar produk klik *Tandai habis* atau *Tandai tersedia*. Produk habis tetap tampil, tombol pesannya nonaktif.
4. **Urutan & sembunyi.** Tombol panah naik/turun mengatur urutan. Saklar menyembunyikan produk tanpa menghapusnya.
5. **Foto produk.** Isi link gambar (https://...) atau nama file yang sudah diupload ke hosting, misalnya `foto/produk-1.jpg`.
6. **Promo & grosir.** Tab *Info & Promo*: centang untuk menampilkan banner promo atau bagian grosir. Isi hanya ketentuan yang benar-benar berlaku.
7. **Ubah nomor WhatsApp.** Tab *WhatsApp*: ketik nomor format 08xx atau +62xx, template pesan bisa diubah dan dites dengan *Tes kirim*.
8. **SIMPAN.** Semua perubahan baru tampil di website setelah klik **Simpan** (atau Ctrl/Cmd+S). Status di atas berubah dari *Belum disimpan* menjadi *Tersimpan*.
9. **Backup.** Tab *Pengaturan* > *Unduh config.json*. Simpan file ini di tempat aman.

**Jangan bagikan password admin kepada siapa pun.**
Jika ada masalah, hubungi pembuat website (Hanriz Digital).
